# **Tomato**

A React service that displays available food on the menu.

---

## Features
- Landing Page
- Login
- Sign Up
- Menu Categories

---

## 📦 Tech Stack
- **Language:** React
- **Styling** CSS

---

## 🛠 Getting Started

### 📂 Clone the Repo
```bash
git clone "https://github.com/theChosenDevop/tomato"
cd tomato
```
### 📦 Install Dependencies
```bash
npm install
```
